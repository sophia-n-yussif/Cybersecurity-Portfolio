# Incident Response Investigation Journal

## Overview

This section contains incident response investigations focused on analyzing cybersecurity incidents, identifying evidence, assessing impact, and developing appropriate response strategies.

The projects demonstrate my understanding of the incident response lifecycle, including identification, analysis, containment, recovery, and lessons learned.

## Incident Investigations

### 1. Phishing-Based Account Compromise

An investigation into a compromised employee account following a phishing attack. This scenario focuses on analyzing suspicious login activity, determining the extent of unauthorized access, evaluating the impact, and recommending security improvements.

### 2. Brute Force Attack Investigation

An investigation into repeated failed login attempts that resulted in unauthorized account access. This scenario focuses on reviewing authentication activity, identifying indicators of compromise, assessing severity, and recommending improvements to account security controls.

### 3. Ransomware Incident Investigation

An investigation into a ransomware attack affecting employee systems and shared resources. This scenario focuses on analyzing the attack timeline, identifying the attack path, determining containment actions, and developing recovery and prevention recommendations.

## Skills Demonstrated

- Incident identification and analysis
- Security event investigation
- Evidence-based decision making
- Impact and severity assessment
- Incident containment strategies
- Root cause analysis
- Recovery considerations
- Security improvement recommendations
- Incident documentation

## Key Takeaways

Through these investigations, I developed a stronger understanding of how security incidents are analyzed and managed. These projects helped me practice:

- Evaluating security events based on available evidence rather than assumptions
- Understanding attacker behavior and attack progression
- Connecting technical findings to business impact
- Developing response recommendations based on risk
- Documenting investigations clearly and professionally
